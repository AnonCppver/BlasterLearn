武器附加与左手校正

地面武器通过 Overlap 建立可拾取目标，客户端操作只发送装备请求，由服务器决定武器归属与主副槽位。主武器固定在人物右手，Weapon Asset 再反向定义左手握点，使相同 Character Skeleton 适配不同枪械。

COND_OwnerOnlyServer RPCRightHandSocketLeftHandSocketFABRIK
Overlap→服务器装备→Socket 附加→FABRIK
  • 01AreaSphere 检测 Pawn，OverlappingWeapon 使用 COND_OwnerOnly，拾取提示只复制给 Character Owner。
  • 02客户端通过 Server RPC 表达装备意图，服务器依据权威 Overlap 结果与 CombatState 决定归属和槽位。
  • 03WeaponState 统一切换拾取碰撞、Physics Simulation 和 Custom Depth；主武器附加到 RightHandSocket，副武器附加到 BackpackSocket。
  • 04每把武器通过 LeftHandSocket 配置握点，Transform 转到 RightHand Bone Space 后由 FABRIK 求解左臂。
  • 05Reloading 时关闭 FABRIK 让 Montage 接管左手；多武器 Overlap 使用候选集合并按准心方向与距离稳定选择 FocusedWeapon。
