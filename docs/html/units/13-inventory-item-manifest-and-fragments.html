Manifest 与 Fragment

同一个 AItem 通过 GameplayTag 标识物品身份，FInvItemManifest 聚合尺寸、图标、堆叠、文本和行为 Fragment。TInstancedStruct<FInvFragment> 在值语义数组中保存不同派生 USTRUCT，并保留类型信息与序列化能力。

GameplayTagFInvItemManifestTInstancedStructFInvFragmentUInvItem
场景配置→Manifest()→运行时 UInvItem→UI / Drop 重建
  • 01ItemType GameplayTag 表达物品身份，FragmentTag 表达数据语义；类型和能力标签彼此独立。
  • 02FInvItemManifest 是完整物品清单，场景 ItemComponent、运行时 UInvItem、描述 UI 和丢弃重建共享同一来源。
  • 03TInstancedStruct<FInvFragment> 解决 TArray 基类值切片和裸指针所有权问题，支持异构派生 USTRUCT 的值语义存储。
  • 04InstancedStruct 保存实际 ScriptStruct 类型和内存，参与 UPROPERTY、Archive 与网络序列化；查询接口按类型及 Tag 安全取回 Fragment。
  • 05Manifest() 创建 UInvItem 并实例化 Fragment；丢弃时把运行时 Manifest 写回新场景 Actor，完成数据往返。
