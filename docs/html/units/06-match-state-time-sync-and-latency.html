GameMode / PlayerController / Time Sync

比赛状态与时间同步

服务器推进 WaitingToStart、InProgress 和 Cooldown，客户端只接收状态与时间基准，并通过多次请求/响应估算服务器时钟。HUD 在本地根据校准后的服务器时间计算倒计时，不需要服务器每秒复制剩余秒数。

MatchStateClientServerDeltaSingleTripTimeSliding WindowHUD
客户端发送时刻→服务器接收时刻→过滤 RTT 样本→GetServerTime
  • 01GameMode 只存在于服务器，PlayerController 将 MatchState 和整条比赛时间轴送到对应客户端。
  • 02中途加入通过 ServerCheckMatchState 补齐当前阶段、LevelStartingTime、WarmupTime、MatchTime 与 CooldownTime。
  • 03每次采样由请求发送时刻和回复抵达时刻得到 RTT，再估算 SingleTripTime 与 ClientServerDelta。
  • 04滑动窗口拒绝异常 RTT，对保留样本平均，GetServerTime() 使用平均时钟偏差减少倒计时与回溯时间抖动。
  • 05自测单程延迟服务于时钟校准；PlayerState 压缩 Ping 服务于高延迟提示，两者数据源和用途分离。
